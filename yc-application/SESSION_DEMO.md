# Product Demo Clip — Real Child Sessions (90–120s)

Separate from the founder video. Magic must be obvious; UI can be ugly.

## Consent (required)

Use the script in `PARENT_OUTREACH.md`. Prefer: child’s face off-camera, nickname only, parent on the call.

## Session plan (15 min live → cut to 90–120s)

1. Create child profile in the app (name, age, interest e.g. cricket / cats / space).  
2. Start a Mentoring Loop session (word-problem path).  
3. Let the child struggle once — do not rescue early.  
4. Watch the tutor diagnose and re-explain a different way.  
5. Child succeeds.  
6. Open Parent view — show “what clicked / what’s stuck” saved to learner model.  
7. Optional: start Session 2 and show it resumes from memory.

## Edit the clip to this beat sheet

| Time | Beat |

## Recording setup

- Chrome + Loom or Win+G / OBS  
- Mic clear; reduce UI chrome if needed  
- Upload unlisted YouTube or Loom  
- Paste into YC **demo** field (not founder video)

## If you cannot get a child before deadline

1. Use **Demo Play** in the app (scripted child responses) and record that.  
2. In the application, be honest: “Prototype demo with scripted learner; live child sessions scheduled [dates].”  
3. Still run real sessions for the interview if invited.
